# PoolIDE

**Stop paying twice for AI.**

PoolIDE is a full AI-powered IDE that works with the AI subscriptions and providers you already have.

Connect your existing AI accounts, work directly on your code, review changes with built-in diffing, and keep or undo edits — all inside a VS Code-based IDE.
